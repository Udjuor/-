# Kerdiis

Время для того, что важно!

Kerdiis — программа для Windows: расписание, посещаемость и документы колледжа в одном окне. Она распределяет студентов на мероприятия. Рассчитана на интерактивные панели в аудиториях и компьютеры преподавателей: крупный интерфейс под палец, запуск вместе с Windows, работа без интернета и обмен данными по локальной сети.

## Что умеет

- Виды на день, неделю и месяц.
- События четырёх типов со своим цветом: занятие, практика, задание, мероприятие.
- Событие: название, дата, время начала и окончания, место, ответственный, участники, техника, примечание.
- Отметка на парах с временем, опозданиями и причинами отсутствия.
- Автоматические отчёты по проведённым парам и посещаемости с сохранением для Excel.
- Автоматическое обновление программы.
- Шесть языков: русский, английский, испанский, китайский, японский и корейский.
- Служебная записка об освобождении от занятий формируется автоматически по шаблону колледжа.
- Бегущая строка напоминаний с цветом и сроком, которую ведут преподаватели.
- Сроки сдачи заданий и материалов мероприятий с отметкой о сдаче.
- Опоздание вручную и отчёт по паре, который фиксируется один раз.
- Занятость техники в реальном времени: сколько занято, у кого и до какого времени.
- Тамагочи группы: пиксельный питомец, здоровье которого зависит от посещаемости.
- Добавление нажатием на время в сетке или кнопкой «Добавить мероприятие».
- Справочники: группы и студенты, техника, преподаватели. Списки можно вставлять столбцом из Excel.
- Участников, технику и ответственного можно выбрать из справочников: студентов по одному, группой или всех сразу. Занятые в это время отмечены. Вписать имя вручную тоже можно.
- Лимиты техники: в событии указывается количество, а больше свободного на это время выбрать нельзя.
- Своя камера студента: не расходует лимит и попадает в список техники сама.
- Тёмная и светлая тема в цветах GitHub, размер интерфейса настраивается на каждом устройстве.
- Техническое задание по событию: чек-лист на печать или в PDF.
- Форма предупреждает, если человек или техника уже заняты в это время. Сохранить всё равно можно.
- Заливка показывает состояние: прошедшее событие серое с цветной полосой, идущее сейчас полностью залито цветом и обведено белым.
- Мероприятие можно показать на всех устройствах или только на выбранных.
- Через 5 минут без касаний панель возвращается к текущей неделе. В полночь сама переходит на новый день.

## Техника и камеры

В разделе «Справочники → Техника» у каждой позиции можно задать количество, например «Камера, 5». Пустое поле означает «без лимита». Таблицу из двух столбцов (название и количество) можно вставить целиком.

В событии технику можно найти поиском по названию, а количество выбирается кнопками − и +. Программа показывает, сколько свободно на это время с учётом других событий, и не даёт выбрать больше. Если вписать технику вручную сверх лимита, сохранить событие нельзя. Устройства без связи могут выдать одно и то же одновременно: после обмена такая нехватка будет видна в форме события.

Если у студента есть своя камера, нажмите «Своя камера» рядом с его фамилией в справочнике. Когда он становится участником события, в список техники само добавляется «Своя камера» с числом таких студентов, а лимит камер не расходуется.

## Техническое задание

Откройте событие и нажмите «Тех. задание». Откроется лист A4 с датой, временем, местом и ответственным. В таблице техники у каждой позиции есть отметки «Подготовлено», «Выдано» и «Возвращено». Каждая строка примечания становится пунктом задач с отметкой, ниже идут участники с группами и строки для подписей. Лист можно напечатать или сохранить в PDF.

## Отметка на паре

Откройте событие и нажмите «Отметка». Студент нажимает на свою фамилию, и программа записывает время с часов компьютера. Если время позже начала, показывается опоздание в минутах. Повторное нажатие снимает отметку.

Причины отсутствия указываются кнопками рядом с фамилией: болезнь, по приказу, уважительная. Участник без отметки после окончания пары считается отсутствующим без причины.

Отметки расходятся по сети. Если разные панели отметили разных студентов одной пары, сохранятся все отметки, а по одному студенту останется более поздняя.

## Отчёты

Кнопка «Отчёты» показывает три таблицы за выбранный период: проведённые пары, посещаемость студентов и сводку по группам. Отбирать можно по типу, группе и преподавателю. Отчёт считается автоматически: проведённой считается пара, время окончания которой прошло, и в «Все пары» входят занятия, практика и задания. Группа студента определяется по справочнику. Открытую таблицу можно напечатать, сохранить в PDF на альбомном листе или записать в файл CSV кнопкой «Сохранить для Excel».

## Служебная записка

Когда участники назначены на мероприятие, практику или задание, при сохранении программа сама заполняет шаблон записки и кладёт файл Word в папку «Документы\Служебные записки». Для занятий записка не создаётся. Новый файл появляется при изменении названия, времени, подготовки, места, ответственного или участников, а если они не менялись, файл не перезаписывается. Если прежний файл открыт в Word, рядом появится копия.

В записку подставляются название, дата и время начала, время освобождения, место, ответственный, студенты с группами и дата документа. Номер записки и подписи заполняются вручную. Строка «От» и подпись настраиваются на каждом устройстве: «Настройки → Служебная записка».

У мероприятия, практики и задания можно указать подготовку до начала в минутах. Время освобождения в записке начинается с подготовки, например при начале в 11:00 и подготовке 60 минут: 10:00–14:30. На это время участники и техника считаются занятыми. На другом устройстве записку можно сформировать кнопкой «Служебная записка» в карточке события. Открыть файл можно программой, которая понимает формат Word.

Шаблон лежит в `src/assets/memo-template.docx`. Менять в нём можно текст вне таблицы записки: программа ищет вторую таблицу из семи строк.

## Тамагочи

У каждой группы свой питомец. Кнопка с ним находится в правом нижнем углу, в окне можно выбрать группу и дать ему имя. Устройство запоминает выбранную группу.

Здоровье пересчитывается по отметкам, поэтому на всех устройствах оно одинаковое. Новый питомец начинает с 70 из 100. После каждой отмеченной пары здоровье меняется: при посещаемости 100% прибавляется 6, при 75% не меняется, при 50% убавляется 8, при полном прогуле убавляется 24. Опоздание считается за половину посещения. Болезнь, приказ и уважительная причина не вредят, а пары без единой отметки и мероприятия не учитываются.

Состояния: от 85 играет, от 60 здоров, от 35 грустит, ниже болеет, при нуле умирает. Умерший питомец не оживает: нужно завести нового, и он не отвечает за прошлые пары.

В окне питомца есть график здоровья за последние 30 учтённых пар, журнал умерших питомцев и, если групп несколько, сводка по всем группам. Смерть попадает в журнал, когда заводят нового питомца.

## Бегущая строка

В нижней строке экрана могут идти напоминания. Вести их можно в версии для преподавателей: кнопка «Напоминания» внизу экрана. У напоминания есть текст, цвет (синий, зелёный, жёлтый, красный) и срок. Когда срок выходит, оно исчезает со всех устройств и остаётся в списке, откуда его можно удалить или продлить. Скорость постоянная, около 9 знаков в секунду.

Кроме того, в строку сами попадают сроки сдачи (сегодня, завтра и просроченные не дольше трёх дней, до пяти штук) и смена состояния питомца любой группы (три дня после пары, на которой оно изменилось). Эти напоминания считаются на каждом устройстве из общих данных, поэтому их не нужно вести вручную. На панели показываются сроки только её событий.

## Две версии

Обе собраны из одной программы и обновляются одинаково, версия сохраняется при обновлении.

- **Клиент для панелей** `Kerdiis-Setup-<версия>.exe`. Можно смотреть календарь, добавлять события и отмечать своё присутствие. В настройках доступны только язык, размер и версия.
- **Версия для преподавателей** `Kerdiis-Admin-Setup-<версия>.exe`. Открыто всё: изменение и удаление событий, отметка о сдаче, справочники, отчёты, настройки, напоминания, питомец, записки, опоздания, причины и фиксация отчёта.

При обновлении с прошлых версий устройство с настройкой «Показывать мероприятия всех устройств» становится версией для преподавателей, остальные клиентами. Сменить версию на установленной программе: запустить нужный установщик или `Kerdiis-Setup-<версия>.exe /S /EDITION=admin` либо `/EDITION=client`.

## Отметки и фиксация отчёта

Студент на панели может только отметить своё присутствие, и это не считается опозданием. В версии для преподавателей доступны кнопка «Опоздал» с редактируемым временем прихода, причины отсутствия и фиксация.

«Зафиксировать и отправить» закрывает отчёт: кто не отмечен, становится отсутствующим, состав пары запоминается, нельзя удалить пару или изменить её время, название и состав. Отчёт по занятию отправляется один раз: повторная отправка отклоняется, а если его зафиксировали с двух компьютеров без связи, остаётся первая фиксация. Отметка с панели, которая была без связи, зафиксированный отчёт не меняет. Исправить его можно только в версии для преподавателей: что было, что стало, с какого компьютера и когда, остаётся в истории.

Защита работает внутри программы. Тот, кто получит доступ к учётной записи Windows и файлам программы, может её обойти. Все устройства должны быть обновлены: версии до 1.18 фиксацию не соблюдают.

## Сроки сдачи

У задания можно указать срок сдачи, у мероприятия — срок сдачи материалов. Срок показывается пунктирной плашкой в календаре на свой день, в карточке события и в техническом задании. Кнопка «Сроки» вверху открывает общий список: просрочено, сегодня и завтра, позже, сдано. Число на кнопке показывает, сколько сроков требуют внимания, красный цвет значит, что есть просроченные.

Сдачу отмечают на всё событие целиком, а не по каждому студенту. Если срок изменить, отметка снимается.

## Занятость техники

Кнопка «Техника» вверху показывает состояние на текущий момент: что свободно и что занято, сколько единиц, у какого ответственного, на каком событии, где и до какого времени, а также ближайшую бронь. Подготовка к событию считается занятостью. Данные обновляются сами раз в минуту и при обмене с другими устройствами. Показывается не факт выдачи, а план: то, что назначено на события.

## Как устроена сеть

Сервер не нужен. Каждый компьютер хранит полную копию мероприятий у себя и работает без сети. Встретив другое устройство, он обменивается с ним недостающими записями.

- **Поиск.** Устройства сами находят друг друга в своей подсети. Адрес хотя бы одного устройства другой подсети указывается в настройках, остальные адреса передаются по цепочке.
- **Когда идёт обмен.** Сразу после изменения, при появлении нового устройства и раз в минуту. Кнопка «Обменяться сейчас» в настройках запускает его вручную.
- **Выключенный компьютер.** Он получит изменения при следующей связи с любым устройством сети, автор при этом может быть уже выключен.
- **Защита.** Весь обмен зашифрован ключом сети (AES-256-GCM), устройства с другим ключом не видят данные и не могут их записать.
- **Одновременные правки.** Если одно мероприятие изменили на двух несвязанных устройствах, останется версия, сохранённая позже. Поэтому часы компьютеров должны идти верно.

Справочники расходятся по сети так же, как мероприятия, поэтому обновите программу на всех устройствах: версии до 1.2.0 их не принимают. Заполнять их можно на любом устройстве.

В мероприятии участники, техника и ответственный хранятся текстом. Если позже переименовать запись в справочнике или удалить её, уже созданные мероприятия не изменятся.

### Добавить мероприятие на другой компьютер

В форме мероприятия есть поле «Где показывать». По умолчанию выбрано «Все устройства». Можно выбрать одну или несколько аудиторий, и мероприятие появится только там. Копии всё равно хранятся на всех устройствах: так запись доходит до выключенных компьютеров, а проверка занятых людей и техники видит всю сеть.

На компьютерах преподавателей включите в настройках «Показывать мероприятия всех устройств».

## Установка

Скачайте `Kerdiis-Setup-<версия>.exe` из раздела **Releases** и запустите его. Нужны права администратора и Windows 10 или 11 (64 бита).

Настройка сети:

1. На первом устройстве откройте настройки и нажмите «Создать» рядом с полем «Ключ сети».
2. На остальных устройствах введите тот же ключ.
3. Дайте каждому устройству понятное название, например «Ауд. 204».

Для установки на все компьютеры сразу, без вопросов:

```bat
Kerdiis-Setup-1.5.0.exe /S /SYNCKEY=ABCDE-FGHJK-LMNPQ-RSTUV /PEERS=10.0.2.15,10.0.3.7
```

`/PEERS` нужен, только если компьютеры находятся в разных подсетях.

Установщик разрешает программе входящие подключения в брандмауэре Windows (порты 47800/TCP и 47801/UDP). Если в сети есть другой брандмауэр, откройте эти порты между устройствами.

Windows SmartScreen может предупредить о неизвестном издателе, потому что установщик не подписан сертификатом. Для запуска нажмите «Подробнее → Выполнить в любом случае».

## Первый запуск

На новом устройстве после панели запуска появляется мастер из четырёх шагов: язык и оформление, название и назначение устройства, ключ сети, данные для служебной записки. Каждый шаг можно пройти или пропустить всю настройку одной кнопкой, всё меняется позже в настройках. Мастер не появляется на устройствах, где программа уже работала, и при установке с готовым ключом `/SYNCKEY`.

## Панель при запуске

При запуске на 4,5 секунды появляется небольшое окно без рамки по центру экрана: название, девиз, автор и версия. Затем открывается главное окно. Нажатие на панель закрывает её сразу.

## Языки

При первом запуске программа берёт язык Windows, а если такого языка нет, включает английский. Устройства, где программа уже работала, остаются на русском. Язык меняется в настройках, после этого программа перезапускается. Он задаётся на каждом устройстве отдельно, а обмен данными между устройствами на разных языках работает.

Данные не переводятся: названия событий, имена и техника остаются такими, как их ввели. Служебная записка формируется на русском, потому что шаблон на русском.

Тексты лежат в `src/renderer/locales`, ключом служит русская фраза. Чтобы добавить язык, нужно создать файл по образцу и внести его в `src/renderer/i18n.mjs` и `src/main/config.js`. Тест проверяет, что переведены все фразы и что в них те же подстановки.

## Автообновление

Обновление не требует действий на панелях и пароля администратора. Программа стоит на весь компьютер, поэтому менять её может только администратор: это делает системная задача Windows `StudentCalendarUpdate`, которая устанавливается вместе с программой.

- Задача запускается через 2 минуты после включения компьютера и ночью, с 3:00 до 4:00.
- Она сверяется с разделом **Releases**, скачивает новую версию, проверяет контрольную сумму и устанавливает её.
- Если программа запущена, она закроется и откроется заново. Данные и настройки сохраняются.
- Результат последней проверки виден внизу настроек программы. Там же кнопка «Проверить обновления»: она запускает проверку сразу, и если новая версия есть, программа закроется, обновится и откроется снова.

Компьютеру нужен доступ к `github.com`. Версии до 1.3.0 обновляться не умеют, поэтому новую версию нужно один раз поставить вручную.

Чтобы выпустить новую версию, опубликуйте на GitHub релиз с меткой вида `v1.6.0` на актуальной ветке `main`. Номер версии программы сборка берёт из метки. Панели получат новую версию сами. Обновление запускается с правами системы на всех компьютерах, поэтому доступ на запись в этот репозиторий должен быть только у доверенных людей.

## Где хранятся данные

Всё лежит в `C:\ProgramData\Kerdiis`: мероприятия в `data\events`, настройки в `config.ini`. Для резервной копии достаточно скопировать эту папку. При удалении программы данные остаются.

## Автозапуск

Установщик добавляет программу в автозагрузку для всех учётных записей компьютера (раздел реестра `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`). Отключить её можно штатно: **Параметры → Приложения → Автозагрузка** или в диспетчере задач.

Программа открывается на весь экран. Кнопка с чертой справа вверху сворачивает её, чтобы освободить доску. Вернуться можно через панель задач или ярлык на рабочем столе. Полноэкранный режим отключается в настройках или клавишей F11.

## Разработка

Нужен Node.js 22.

```bash
npm install
npm start        # запуск
npm test         # модульные тесты
npm run dist     # сборка установщика, запускать на Windows
```

`scripts/e2e.cjs` проходит основные сценарии на запущенной программе. При каждом изменении в `main` GitHub Actions собирает установщик, ставит его на чистую Windows и проверяет автозапуск, работу программы и удаление. Новая версия выпускается так: на GitHub откройте **Releases → Draft a new release** и создайте метку вида `v1.6.0`. Сборка возьмёт номер из метки и сама добавит в релиз установщик и `latest.yml`.

```
src/main/       запуск окна, настройки, хранение мероприятий, обмен между устройствами
src/renderer/   интерфейс; logic.mjs содержит логику без привязки к странице
build/          значок и дополнительные шаги установщика
```
