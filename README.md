# Календарь мероприятий

Программа для Windows, которая распределяет студентов на мероприятия. Рассчитана на интерактивные панели в аудиториях: крупный интерфейс под палец, запуск вместе с Windows, работа без интернета.

## Что умеет

- Виды на день, неделю и месяц.
- Мероприятие: название, дата, время начала и окончания, место, ответственный, участники, техника, примечание.
- Добавление нажатием на время в сетке или кнопкой «Добавить мероприятие».
- Список участников можно вставить столбцом из Excel.
- Форма предупреждает, если человек или техника уже заняты в это время. Сохранить всё равно можно.
- Цвет показывает состояние: тёмный блок уже прошёл, жёлтый идёт сейчас, светлый впереди.
- Через 5 минут без касаний панель возвращается к текущей неделе. В полночь сама переходит на новый день.

## Установка

Скачайте `StudentCalendar-Setup-<версия>.exe` из раздела **Actions → последняя сборка → installer** или из **Releases**, затем запустите его. Нужны права администратора и Windows 10 или 11 (64 бита).

Для установки на все панели сразу, без вопросов:

```bat
StudentCalendar-Setup-1.0.0.exe /S /DATADIR=\\server\calendar
```

Windows SmartScreen может предупредить о неизвестном издателе, потому что установщик не подписан сертификатом. Для запуска нажмите «Подробнее → Выполнить в любом случае».

## Общие данные на всех панелях

По умолчанию мероприятия хранятся на самом компьютере, в `C:\ProgramData\StudentCalendar\data`. **В таком режиме каждая панель видит только свой календарь.**

Чтобы панели показывали одно и то же:

1. Создайте на сервере или на одном из компьютеров сетевую папку.
2. Дайте учётным записям панелей право на изменение в ней.
3. Укажите её при установке через `/DATADIR=` или в программе: кнопка настроек → «Папка с мероприятиями».

Изменения с других панелей появляются в течение 10 секунд. Если папка недоступна, программа сообщает об этом, оставляет на экране уже загруженные данные и подключается сама, когда папка вернётся. Если два человека правят одно мероприятие одновременно, второй получит предупреждение, и чужие изменения не затрутся.

Резервная копия — это обычное копирование папки с данными. Каждое мероприятие лежит в ней отдельным файлом в папке `events`.

## Автозапуск

Установщик добавляет программу в автозагрузку для всех учётных записей компьютера (раздел реестра `HKLM\Software\Microsoft\Windows\CurrentVersion\Run`). Отключить её можно штатно: **Параметры → Приложения → Автозагрузка** или в диспетчере задач. При удалении программы запись удаляется, а мероприятия и настройки остаются.

Программа открывается на весь экран. Кнопка с чертой справа вверху сворачивает её, чтобы освободить доску. Вернуться можно через панель задач или ярлык на рабочем столе. Полноэкранный режим отключается в настройках или клавишей F11.

## Настройки

Хранятся в `C:\ProgramData\StudentCalendar\config.ini`, файл можно подготовить заранее:

```ini
[calendar]
dataDir=\\server\calendar
fullscreen=1
```

При записи через `/DATADIR=` используйте путь латиницей. Путь с кириллицей укажите в настройках программы.

## Разработка

Нужен Node.js 22.

```bash
npm install
npm start        # запуск
npm test         # модульные тесты
npm run dist     # сборка установщика, запускать на Windows
```

`scripts/e2e.cjs` проходит основные сценарии на запущенной программе. При каждом изменении в `main` GitHub Actions собирает установщик, ставит его на чистую Windows и проверяет автозапуск, работу программы и удаление. Метка вида `v1.0.1` дополнительно публикует релиз.

```
src/main/       запуск окна, настройки, хранение мероприятий
src/renderer/   интерфейс; logic.mjs содержит логику без привязки к странице
build/          значок и дополнительные шаги установщика
```
